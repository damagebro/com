# sim_pipe

| 模块                    | 说明 |
| ----------------------- | ---- |
| `com_pipe_vld_single`   | 单级 valid pipe |
| `com_pipe_vld`          | 多级 valid pipe |
| `com_pipe_rdy`          | ready pipe with data |
| `com_pipe_vld_rdy`      | valid/ready pipe |
| `com_pipe_regslice`     | 多级 valid/ready regslice |

不覆盖 `com_reg*`。
